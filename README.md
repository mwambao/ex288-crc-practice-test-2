# EX288 CRC Practice Test 2

A second, independent CRC practice set derived from the two user-provided study documents and structured like the existing remediation lab.

1. Rebuild/verify CRC using `docs/PREREQUISITES.md` and `scripts/verify-env.sh`.
2. Push the `repos/pt2-*` directories to Git and note your `<GIT_BASE>`.
3. Run `./scripts/setup.sh`.
4. Attempt `docs/MOCK-EXAM.md` without solutions.
5. Mark with `./scripts/mark.sh 1` or `./scripts/mark.sh all`.
6. Review `docs/SOLUTIONS.md`.
